# 台灣口罩查詢系統

## 專案介紹
本專案於 COVID-19 疫情期間開發，透過政府公開資料 API 即時取得口罩庫存資訊，並提供藥局口罩剩餘數量查詢功能。

## 功能
- 即時取得口罩資料
- 顯示藥局名稱
- 顯示地址
- 顯示成人口罩剩餘數量
- 顯示兒童口罩剩餘數量
- 將資料轉換為 JSON 格式

## 使用技術
- PHP
- CSV 資料處理
- JSON
- 政府 Open Data API

## 注意事項
本專案使用的疫情期間政府口罩公開資料來源目前已停止維護，因此即時查詢功能已失效。本專案主要作為資料處理與 API 串接練習展示。
